# Children of the Moon – Test Releases

This repository distributes **compiled Windows test builds only**. The game's source code remains in a separate private repository.

Testers should use the Children of the Moon Launcher to download approved releases. Builds are experimental; do not treat them as stable releases.

No source code, credentials or secrets are published here.
